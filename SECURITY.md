# Configuration and historical copies

Use credentials from your own provider account through environment variables. The offline checks never contact Telegram, Discord, OpenWeather or betting providers.

Historical commits may contain values that were removed from current source. Removal is not revocation: the account owner must revoke/rotate any still-active or reused values at the provider before a separately reviewed history cleanup. Do not post values in issues or logs. This repository does not claim that historical credentials were invalidated.
